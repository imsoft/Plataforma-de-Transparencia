# Entregable 9 — Plan de seguridad (cobertura de la sección 9 por punto y fase)

| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | ------------------------------------- |
| **9.1 Cuentas**                                       |                                                                                                                                                                                                                                                                                                                                        |                             |                                       |
| 2FA obligatoria superadmin/supervisor/admin municipal | plugin `twoFactor` (TOTP + códigos de respaldo). Middleware del panel: si el rol lo exige y `user.twoFactorEnabled=false`, solo puede entrar a `/configurar-2fa`                                                                                                                                                                       | `packages/auth`             | 1                                     |
| Contraseñas ≥ 12 y no filtradas                       | `password.minLength: 12` + plugin `haveIBeenPwned` (k-anonymity, no manda la contraseña)                                                                                                                                                                                                                                               | `packages/auth`             | 1                                     |
| Límite de intentos y bloqueo progresivo               | rate limit de Better Auth en `/sign-in/email` (5 intentos / 15 min por correo+IP) + bloqueo progresivo propio (tabla `intentos_login`) ; correo "intentos fallidos" y "inicio desde dispositivo nuevo" (hash de UA+IP en `session`)                                                                                                    | `packages/auth`             | 1 (correos de dispositivo nuevo: 1.5) |
| Sesiones y revocación                                 | expiración 7 días con renovación; `revokeUserSessions` al dar de baja o cambiar contraseña; baja = `member` eliminado + usuario `banned` si no tiene otra membresía                                                                                                                                                                    | panel                       | 1                                     |
| Una cuenta por persona                                | invitación por correo individual; el panel rechaza correos genéricos ya usados y la pantalla de invitación lo explica                                                                                                                                                                                                                  | panel                       | 1                                     |
| Mínimo privilegio                                     | roles `migraciones` / `app_panel` / `lector_publico`; token R2 del panel con `PutObject/GetObject/CopyObject/DeleteObject` solo en el bucket; sitios sin credenciales de R2 ni de escritura                                                                                                                                            | `packages/db`, infra        | 1                                     |
| **9.2 Aplicación**                                    |                                                                                                                                                                                                                                                                                                                                        |                             |                                       |
| Denegar por defecto                                   | `puede(ctx, accion, recurso)` devuelve `false` salvo regla explícita; toda Server Action la llama antes de `conUsuario`; pruebas por rol                                                                                                                                                                                               | `packages/auth/permisos.ts` | 1                                     |
| Validación con Zod, SQL parametrizado                 | esquema zod por acción; Drizzle; `sql` template solo en `packages/db`                                                                                                                                                                                                                                                                  | todo                        | 1                                     |
| IDs no adivinables                                    | uuid v7 interno, nanoid(12) en `/d/<id>`, nanoid(6) en el nombre de archivo                                                                                                                                                                                                                                                            | `packages/db`               | 1                                     |
| CSRF y cookies                                        | Better Auth: cookies `HttpOnly; Secure; SameSite=Lax`, verificación de origen; Server Actions de Next verifican `Origin`                                                                                                                                                                                                               | panel                       | 1                                     |
| Cabeceras                                             | `next.config` compartido en `packages/config`: CSP estricta con nonce (sin `unsafe-inline` en scripts), HSTS preload, `frame-ancestors 'none'` (sitios: `'self'` para incrustar videos externos solo en `frame-src`), `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, `nosniff`                              | todas las apps              | 1                                     |
| Rate limiting                                         | **Decisión pendiente:** `@upstash/ratelimit` + Upstash Redis (gratis hasta 10k cmd/día) **o** tabla `rate_limit` en Postgres (sin servicio nuevo, suficiente para este volumen). Recomiendo Postgres en MVP y Upstash si hay abuso. Límites: login, invitaciones (10/h por admin), firmar URL (60/min por usuario), revalidar (30/min) | panel                       | 1                                     |
| WAF                                                   | Vercel Firewall (reglas gestionadas + bloqueo de bots en el panel) y Cloudflare proxy delante de `archivos.*`                                                                                                                                                                                                                          | infra                       | 1 (configuración)                     |
| Endpoint de revalidación                              | Bearer + `timingSafeEqual`, cuerpo acotado, solo POST                                                                                                                                                                                                                                                                                  | `packages/transparencia`    | 1                                     |
| Errores sin detalle                                   | `error.tsx` genérico; detalle a Sentry con `beforeSend` que quita cabeceras y cuerpos                                                                                                                                                                                                                                                  | todas                       | 1                                     |
| **9.3 Archivos**                                      |                                                                                                                                                                                                                                                                                                                                        |                             |                                       |
| Tipo real                                             | subida directa a R2 → tras `completar`, el panel lee los primeros 4 KB con `GetObject Range` y `file-type`; si no coincide con lo permitido, borra el objeto y responde error claro. CSV (texto plano) se valida por extensión + que sea UTF-8 sin bytes nulos                                                                         | `packages/archivos`         | 1                                     |
| Tamaño máximo                                         | `ContentLength` fijado en la URL firmada (PUT simple) y validación del tamaño total al completar multipart; `configuracion` por tipo                                                                                                                                                                                                   | `packages/archivos`         | 1                                     |
| ZIP sin procesar                                      | se sirven como `attachment`; nunca se abren en servidor                                                                                                                                                                                                                                                                                |                             | 1                                     |
| Nombre saneado                                        | el nombre original solo va a `documento_versiones.nombre_original`; el objeto usa el slug + id                                                                                                                                                                                                                                         |                             | 1                                     |
| Dominio separado                                      | `archivos.<plataforma>.mx` (dominio público de R2 vía Cloudflare); `Content-Type` y `Content-Disposition` se fijan como metadatos del objeto al subir y al mover; PDFs e imágenes `inline`, el resto `attachment`                                                                                                                      |                             | 1                                     |
| Antivirus                                             | ClamAV en contenedor aparte (Fly.io o Railway, ~5 USD/mes, te aviso antes) que escanea al completar y marca `documento_versiones.escaneo`                                                                                                                                                                                              |                             | 2                                     |
